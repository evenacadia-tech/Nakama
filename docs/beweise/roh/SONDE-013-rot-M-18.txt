SONDE-013 Etappe 2 E - Rotbeweis M-18
=========================================

Datei:     eq-copilot/plugin/tests/Sonde013PrePostGoldenTest.cpp
Ziel:      EqCopSonde013PrePostGoldenTest (Kanon B24)
Warum:     Die zweite Wache mittelt die Relationsstreuung ueber die Baender, statt sie je Band zu rechnen. Eine nichtlineare Kette wirkt bandabhaengig verschieden; der Mittelwert ueber 149 Baender loescht genau das aus. Danach faellt die Kompression durch KEINE der beiden Wachen - sie haelt die Kohaerenzschwelle aus §38.3, und ihre gemittelte Streuung ist von der eines Kabels nicht zu unterscheiden. Genau das haette dem haeufigsten Geraet der Kette einen festen Uebertragungsfrequenzgang zugeschrieben.

Eingebauter Fehler (alt -> neu):
--- ALT ---
        if (reihe.size() < 3)
            continue;
        const double mittel = std::accumulate (reihe.begin(), reihe.end(), 0.0)
                            / (double) reihe.size();
        double q = 0.0;
        for (double v : reihe)
            q += (v - mittel) * (v - mittel);
        streuungen.push_back (std::sqrt (q / (double) reihe.size()));
--- NEU ---
        if (reihe.size() < 3)
            continue;
        const double mittel = std::accumulate (reihe.begin(), reihe.end(), 0.0)
                            / (double) reihe.size();
        double q = 0.0;
        for (double v : reihe)
            q += (v - mittel) * (v - mittel);
        // Rotbeweis: erst ueber die Baender mitteln, dann streuen.
        streuungen.push_back (std::sqrt (q / (double) reihe.size()) / 40.0);

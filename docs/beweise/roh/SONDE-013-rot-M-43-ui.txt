=========================================

Datei:     eq-copilot/plugin/core/analysis/Blindvergleich.h
Ziel:      EqCopSonde013ExperimentUiTest (Kanon B26)
Warum:     Die Gen-Seite nimmt ein Klangurteil ohne eingefrorenen Vergleichspegel an. Damit gaebe es die Zusage aus §15 nur noch im Broker - und die UI koennte ein Urteil sammeln, das der Store danach ablehnt. Eine Sperre, die nur an einer der zwei Stellen sitzt, ist keine.

            return Urteilsperre::ohneLautheitsabgleich;

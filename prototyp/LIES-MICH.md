# Prototyp

Hier entsteht der lebende Web-Prototyp: statisches HTML/CSS/JS, ohne
Build-Kette, per Doppelklick im Browser lauffähig.

Die erste Entscheidung — ein Blatt pro Oberfläche oder ein Blatt mit
Tabs — wird MIT dem User getroffen, bevor die erste Datei entsteht.
Jedes Blatt trägt das Editor-Panel (Look-Regler, Zustands-Schalter,
Varianten-Vergleich) von Anfang an.

SONDE-013 Etappe 2 E - Rotbeweis M-25-dirty
=========================================

Datei:     eq-copilot/plugin/src/PluginProcessor.cpp
Ziel:      EqCopSonde013PassageStateTest (Kanon B23)
Warum:     Das Vergessen einer Passage meldet dem Host KEIN Dirty. Die State-Invariante aus CLAUDE.md sagt: "jede persistente Aenderung meldet dem Host Dirty-State" - ein Loeschen, das der Host nicht mitbekommt, kaeme beim naechsten Oeffnen des Projekts zurueck. Der Fehler ist unsichtbar, solange man nur das Merken prueft.

Eingebauter Fehler (alt -> neu):
--- ALT ---
        zustand.manuellePassagen.erase (gefunden);
    }
    // Das Vergessen meldet Dirty wie das Merken. Ein Loeschen, das der Host
    // nicht mitbekommt, kaeme beim naechsten Oeffnen zurueck.
    meldeHostDirty();
--- NEU ---
        zustand.manuellePassagen.erase (gefunden);
    }
    // Das Vergessen meldet Dirty wie das Merken. Ein Loeschen, das der Host
    // nicht mitbekommt, kaeme beim naechsten Oeffnen zurueck.

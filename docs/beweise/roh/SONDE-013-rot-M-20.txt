SONDE-013 Etappe 2 E - Rotbeweis M-20
=========================================

Datei:     eq-copilot/plugin/core/analysis/Vergleichspegel.h
Ziel:      EqCopSonde013PrePostGoldenTest (Kanon B24)
Warum:     Der Vergleichspegel rechnet bei jeder Abfrage neu, statt den eingefrorenen Wert zu halten - die kontinuierliche automatische Nachregelung, die §38.3 ausdruecklich ausschliesst: sie "kann Transienten und Stille falsch bewerten und wird selbst zum hoerbaren Prozessor". Der Fehler sieht wie eine Verbesserung aus (der Wert ist ja immer aktuell) und veraendert genau das, was der User waehrend des Beurteilens hoert.

Eingebauter Fehler (alt -> neu):
--- ALT ---
    double gainDb() const noexcept { return gehalten; }
--- NEU ---
    double gainDb() const noexcept
    {
        if (gesehen == 0 || summeA <= 0.0 || summeB <= 0.0)
            return gehalten;
        return 20.0 * std::log10 (std::sqrt (summeB / (double) gesehen)
                                / std::sqrt (summeA / (double) gesehen));
    }

--- ALT ---
        if (istEingefroren || a == nullptr || b == nullptr || n <= 0)
            return;
--- NEU ---
        if (a == nullptr || b == nullptr || n <= 0)
            return;

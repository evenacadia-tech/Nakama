SONDE-013 Etappe 2 E - Rotbeweis M-61
=========================================

Datei:     broker/src/coordinator/intervention.rs
Ziel:      sonde013_taint.rs (Kanon A4)
Warum:     Ein `end` auf eine unbekannte Intervention-ID loest das sticky `intervention_state_unknown`, statt es zu setzen. Das Begin kann vor Reconnect oder Overflow verloren gegangen sein - ein `end` ist dann gerade KEIN Beweis, dass alles sauber ist. M-61 verlangt ausdruecklich ein Gegenbeispiel dafuer, und beim Bau kam dieser Rotbeweis zuerst gruen zurueck: der Testfall hatte eine Sequenzluecke davor, und damit brach `intervention_end` schon an der Sequenz ab, ohne den ID-Zweig zu erreichen.

Eingebauter Fehler (alt -> neu):
--- ALT ---
        if !passt {
            // Ein End ohne bekanntes Begin ist gerade KEIN sauberer
            // Neutralzustand: das Begin kann vor Reconnect/Overflow verloren
            // gegangen sein. Nur `neutral_resync` darf dieses Urteil loesen.
            stand.intervention_state_unknown = true;
            return false;
        }
--- NEU ---
        if !passt {
            stand.intervention_state_unknown = false;
            return false;
        }

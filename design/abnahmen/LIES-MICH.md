# Abnahmen — bindende User-Urteile

Eine Datei pro Abnahme: `JJJJ-MM-TT-<thema>.md`. Inhalt:

- das **wörtliche** User-Urteil (Zitat),
- was damit festliegt (ein bis drei Sätze),
- was ausdrücklich offen bleibt.

## Zwei Sorten, und sie werden nicht verwechselt

**Abnahme** — bindend. Wird nicht ohne neues User-Wort wieder geöffnet.
Voraussetzung: der User konnte das beurteilen, was tatsächlich zur Debatte
stand. Größen, Anordnungen, Zustände, Methodenfragen.

**Arbeitsannahme** — vorläufig, mit **benanntem Prüfpunkt**. Nötig immer dann,
wenn eine Entscheidung an etwas gemessen wurde, das noch nicht existiert. Eine
visuelle Richtung, gewählt an einem 448×310-Ausschnitt ohne Layout und ohne
echte Fenstergröße, ist genau das: sie war *zu diesem Zeitpunkt* logisch. Ob
sie trägt, zeigt sich erst am fertigen Layout in echter Größe.

Solche Dateien tragen oben ein `⚠ ARBEITSANNAHME`-Kästchen mit dem Prüfpunkt.
Sie darauf zurückzunehmen ist **kein Rückschritt**, sondern der vorgesehene
Weg. Claude darf sie nicht als abgenommen zitieren.

Der Fehler, aus dem diese Unterscheidung entstand: Claude hat „logisch zu
diesem Zeitpunkt" als „entschieden" verbucht und im Sessionbericht als
Festlegung geführt.

Festgelegtes wird nicht ohne neues User-Wort wieder geöffnet. Am
Sessionende kommt eine Zeile dazu, was offen blieb — Wissen lebt in
diesen Dateien, nie im Gedächtnis einer Session.

### Konsequenz für das Gate

Sechs von 25 G2-Primaries hat dieser Lauf nicht reproduziert, obwohl der Defekt
nachweislich fortbesteht — vier davon in Dateien, die seit G2 kein Zeichen
geändert haben. Umgekehrt hat G3 in unverändertem Code drei bestätigte Defekte
gefunden, die G2 übersehen hatte (STRCMP-001, NONDET-001, UNWRAP-001), plus
einen als LIKELY_FP eingestuften (STRSLICE-001). Zwei Läufe mit
identischen Parametern über denselben Code liefern also **keine deckungsgleiche
Menge**. Für das Gate folgt daraus: G2 und G3 sind zusammen zu lesen, und ein
Befund gilt erst dann als erledigt, wenn er am Code widerlegt oder behoben ist
— nicht schon dann, wenn ein späterer Lauf ihn nicht erneut meldet.
